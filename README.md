# ProyectoVisualizacionDatos_DENUE
Visualizacion de datos del DENUE - DIRECTORIO DE UNIDADES ECONOMICAS DE MEXICO

Fuente de datos:

Fuente: Instituto Nacional de Estadistica y Geografia INEGI
Conjunto de datos: DENUE 2026 
Cobertura: Aguascalientes, Mexico.
Publicacion: Mayo 2026.
Formato: CSV
Variables de interes: nombre del establecimiento, activida economica, personal ocupado, municipio, localidad, tipo de asentamiento,
fecha de alta al DENUE.
