# ProyectoVisualizacionDatos_DENUE
Visualizacion de datos del DENUE DIRECTORIO ESTADISTICO NACIONAL DE UNIDADES ECONOMICAS

# Descripción del proyecto:
Este proyecto analiza la distribución de las unidades económicas del Directorio Estadístico Nacional de Unidades Económicas (DENUE) del INEGI en el estado de Aguascalientes.

El objetivo es identificar la distribución geográfica de los establecimientos y su relación con los municipios y las actividades económicas.

# Fuente de datos: 
Fuente: Instituto Nacional de Estadistica y Geografia INEGI

Conjunto de datos: DENUE 2026 

Cobertura: Aguascalientes, Mexico.

Publicacion: Mayo/2026.

Formato: CSV

Variables de interes: nombre del establecimiento, activida economica, personal ocupado, municipio, longitud, latitud, fecha de alta al DENUE.

Fuente de descarga del DENUE Aguascalientes: https://www.inegi.org.mx/app/descarga/default.html

# Estructura del proyecto

notebooks/: notebooks de carga, limpieza y análisis.

data/: documentación y referencias de los datos.

images/: capturas de las visualizaciones finales.
